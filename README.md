这是第三版首页的**初版**，单独放在 `d:\零杯\人间有味-新新版\`，原来的 `人间有味-新版\` 与更早的 `人间有味\` 都完整保留，可以随时对比、回退。

## 一、怎么看

双击 **`打开人间有味.bat`**。它会启动本机 **街尾邮局**，再打开 `http://127.0.0.1:8787/`。  
建议用 Chrome / Edge，需要开启 WebGL。  
也可以直接双击 **`index.html`** 离线看长街；离线时明信片仍可写、可下载，但寄不进收件箱。

打开后：

- 看到巷口、灯笼和“人间有味”，点“走进烟火街”或直接向下滚。
- 滚动就是油门：镜头连续往街里走，不是一屏一屏翻页。
- 走到铺子前会出现底部介绍卡；门脸或柜台可点，点击进入对应板块。
- 五个档口按 **人间烟火 → 水土 → 时节 → 匠心 → 记忆** 排列，街景、右上角板块导航、手机菜单和街尾目录都是同一顺序。
- 每个板块展示完都有“回到长街”。回去时**不重播开头**，直接停在刚离开的那家铺子前，并提示“从这里，继续往街里走”；走过的铺子会在右侧路线轨上留下标记。
- 板块页右上角只保留五个板块名称，不再放“下一章”，避免把用户带离长街顺序。
- 天色随滚动从黎明、正午、黄昏走到深夜；街尾是一道门洞，门洞后面还有一条更深的街。

五个档口对应的页面：

```text
老张早点 → yanhuo.html   第一章 人间烟火
三省食铺 → shuitu.html   第二章 水土（湖北 / 江西 / 山东）
晚市菜场 → shijie.html   第三章 时节
老炉面坊 → jiangxin.html 第四章 匠心（兔子厨房 · 热干面）
街尾邮局 → jiyi.html     第五章 记忆（写一张明信片）
```

### 街尾邮局 · 本机后端

- 零依赖 Node 服务：`node server/server.js`，只绑定 `127.0.0.1:8787`，不连外网、不装 npm 包。
- 收件箱：`http://127.0.0.1:8787/admin.html`。
- 邮差口令：启动终端会打印；也保存在 `data/admin-code.txt`。口令忘了，删掉这个文件再重启，会生成新的。
- 登录令牌只放 `sessionStorage`，12 小时后失效；后台图片接口需要令牌，`data/` 目录不对浏览器公开。
- 写信页的草稿仍只存在本机 `localStorage`。点“寄到街尾”时，才把**合成后的那张明信片 JPEG**和文字、类别、模板交给本机后台；原始照片不会被单独上传。
- 收件箱支持全部 / 未读 / 星标筛选、搜索、标已读、加星、放大查看、撤下，手机也能用。
- 数据落在 `data/postcards.json` 与 `data/uploads/`。想清空街尾，停掉服务后删掉这两项即可。

## 二、这一版做了什么

- **真正的 3D 长街**：一条可前进的老巷，左右两侧店铺、墙面、门洞、瓦顶、灯笼、石板路都是 Three.js 场景，不是一张横图平移。
- **滚动当油门**：滚动条控制镜头路径，带阻尼、步伐起伏和轻微左右摆动；鼠标移动会带来一点视线偏移。
- **实拍门脸 + 3D 街景结合**：五个铺面的门脸使用实拍图，照片外再包木框、屋檐、柜台、布帘、灯笼和道具，让照片成为街的一部分。
- **门脸更清楚、店名立起来**：五张铺面原图放大 2.4–3 倍并轻度锐化，重新内嵌进 `assets/3d/textures.js`；原来悬在屋檐上方、镜头里看不到的横匾，改成挂在靠街檐柱上的竖招，铺名四个字竖排（老张早点 / 三省食铺 / 晚市菜场 / 老炉面坊 / 街尾邮局），停在店前时信息卡不挡字；停店机位视线略抬高，门脸上的“早点”“食铺”等布幌也完整露出。
- **铺前小景**：蒸笼、面锅、菜筐、晾面、邮筒、长凳等是逐件搭的 3D 小道具；蒸笼和面锅会冒热气。
- **从早走到晚**：天空、雾、灯笼亮度、店铺照片染色、曝光一起随时间变化；灯笼和窗纸在夜里会亮。
- **街尾门洞**：门洞后面藏着一张更深的街景，只从门洞和瓦顶之间露出来，不再是贴在天上的大照片。
- **可点击**：门脸有悬停提示；点门脸/柜台/介绍卡都会先压暗并显示店名，然后进入对应页面。
- **半透明鎏金店卡**：五家店的介绍卡统一改成半透明黑玻璃，透出身后街景，配金色细边、柔和金色反光和鎏金标题；底部文字保留深色投影，背景再杂也仍然读得清。
- **手机版**：竖屏下改为全宽底部卡片，隐藏右侧进度轨与 HUD，避免遮挡画面；卡片和按钮在视口内完整可点。
- **一方水土重做**：`shuitu.html` 从旧九宫格改成“中国地图 → 省份六图 3D 环”两层结构；三省各三道菜、每道两张图，第一张讲渊源、第二张讲食材 · 做法 · 味道，悬停或轻点浮出小标签。
- **味觉记忆重做**：`jiyi.html` 先是一整屏暖黑夜色：鎏金点阵毛笔标题、棕榈影、脚印和一张更大的斜放街景明信片；点香槟金按钮“写一张明信片”后进入第二屏，左上角是一小片持续流动的墨金海，右侧保留原来的类别、菜名、回忆、横/竖模板、照片、旅程小签、实时预览、PNG 下载与本机保存。
- **导航与街景对齐**：右上角、手机菜单和页脚都统一成“人间烟火 - 水土 - 时节 - 匠心 - 记忆”；删掉“下一章”跳转与首页街尾目录，只留五个板块标签与“回到长街”。
- **续走而不是重来**：从板块返回时带 `?from=店铺键`，首页跳过巷口片头，把镜头落到刚离开的铺子，并显示“已回到…从这里继续往街里走”的提示；右侧路线轨用金色虚线标出走过的店。
- **店名与门脸贴合五个板块**：江城面馆改为 **三省食铺**（对应水土），老炉卤味改为 **老炉面坊**（对应匠心的一碗面）；门脸统一换成食铺与面馆实拍图，布幡、案上面碗、竹篮与晾面等 3D 小景一起对齐；老张早点、晚市菜场、街尾邮局保留。
- **街尾邮局后台**：零依赖 Node 本机服务、私密收件箱、口令登录、未读/星标/搜索/删除、受保护的明信片图片接口；写信页新增“寄到街尾”，支持离线降级。
- **统一字体与阅读尺度**：六个公开页面统一用 **阿里妈妈东方大楷** 写标题、**寒蝉正楷体** 写正文；正文基准 17px、行高 1.8，各页导语、人物卡、菜品介绍、季节文案、写信表单都相应放大。记忆粒子标题、手机鎏金菜单、印章与手写句继续保留毛笔特效字。字体做成约 468KB / 587KB 的本地 WOFF2 子集，`file://` 离线也能显示；水土九道菜的介绍文字同时做了精简，放大后不再需要滚动。
- **首页题字更重、更亮**：首页“人间有味”改用东方大楷字族，字号放大到桌面约 180px、手机约 73px，颜色换成由浅金到铜金的鎏金渐变，并加了三层暖金/深墨投影；仍是可缩放的文字，不依赖图片。
- **全站循环背景音乐**：`11月11日.mp3` 从六个公开页面的导航一起播放，循环不中断；顶部新增“音乐”键，可调节音量、静音、暂停/继续。浏览器禁止自动出声时，音乐键会轻轻发光，第一次点击页面即开始；音量、静音、暂停状态存在本机，播放进度存在当前浏览会话，换页后接着放。人间烟火页优先保留影像原声：影像播放时背景音乐淡出，暂停或结束后再淡入接回。
- **小标题与副句重写**：首页题字下的两句、烟火页街坊标题与返程导语、水土页地图导语与返程导语、时节页主标题与返程导语、匠心页开场说明与照片墙标题、记忆页封面导语都换成了更顺口、更有画面的说法。
- **记忆页减负**：删掉写信面板下方“邮局未启动”的小字提示与启动教程；真正寄送失败时仍用页面内的 toast 提示，不影响操作。
- **窄屏导航收紧**：440px 以下把“回到长街”收成箭头（可访问名称保留），菜单键固定 40px 不再被挤压；360px 以下再把题名缩一号。320px 宽的旧手机上，返回、题名、音乐、菜单四件也完整落在一排里，互不重叠。

## 三、人间烟火页（本轮新增）

入口：在 3D 长街走到 **老张早点**，点门脸 / 柜台 / 底部卡片，进入 `yanhuo.html`。

### 1. 开场

- 画面仍是清晨长街，只是把 3D 街景截成一张干净的背景图，和首页保持同一色调，**不是黑底 PPT**。
- 正中是四个毛笔字“人间烟火”，下面三句小字：“一屉一屉地蒸，一碗一碗地盛。/ 天还没亮，街口先有了热气。/ 这是三户街坊的一天。”
- 字是本地打包的马善政毛笔字体（Ma Shan Zheng），金色渐变；旁边一枚小小的“肆”印章。
- 约 **4.2 秒**后自动入席；也可以点画面、滚轮、上滑、回车或空格提前跳过，底部有“跳过片头”。

### 2. 转场与影像

- 标题用 1.55 秒移到左上角并缩小，正文与右侧影像同时淡入；标题下面有一道手绘墨线。
- 正文与影像按 **4:6** 分栏：左侧文字约占四成，右侧影像约占六成，桌面 1440 宽时画面约 821px，比上一版更大。
- 右侧播放 `assets/yanhuo/renjian-yanhuo.mp4`（约 1 分 08 秒，循环）。
- 默认**自动播放并尝试开声**：
  - 浏览器允许时直接带声音播放；
  - 浏览器拦截自动播放时，自动退回静音播放，画面左下出现“声音被浏览器拦住 · 点一下画面”，点画面即可开声。
- 自带控制条：播放/暂停、拖动进度、静音、全屏；空格暂停/播放，进度条支持方向键、Home、End。
- 手机端控制条常显，避免hover才能操作。

### 3. 三张街坊便签 · 三炉全屏人物志

- 底部三张**半透明黑玻璃 + 金色描边**的悬浮卡：爱心厨房（万佐成、熊庚香）、乐山粽子（陈少洪）、安阳捋面（王永法）；顶部一道金色细线和小菱形像钉在街上的便签，鼠标掠过会轻轻抬起。
- 姓名用鎏金渐变，照片配金边细框，整张卡既透出街景，又不至于让字被背景吃掉。

**三炉共用一套全屏版式**

- 点击任意一张便签，进入深褐暖黑 + 鎏金的全屏人物志，不再使用旧的故事弹层。第一炉、第二炉、第三炉只在内容上换，版式完全一致。

- 背景图与故事数据一起在 `FEATURE_STORIES` 里配置，页面初始化时预载，切换人物不会空一拍。
- 左侧按“栏目 → 姓名 → 身份 → 引言 → 正文 → 数字 → 落款”的顺序排出文字层级：
  - 第一炉：万佐成 · 熊庚香，“炉”印，二十载 / 一元 / 百家炉；
  - 第二炉：陈少洪，“粽”印，三十余年 / 五毛 / 一桶；
  - 第三炉：王永法，“面”印，六代 / 三饧三揉 / 一捧面。
- 右侧是胶片长条，三格窗口固定不动：
  - 爱心厨房 7 张、乐山粽子 4 张、安阳捋面 5 张，每张复制两遍组成循环轨道；
  - **每 4 秒整体向左推一格**（约 3 秒停留完整画面、1 秒滑行）；三炉分别 28 秒、16 秒、20 秒走完一圈，接回起点时无缝衔接；
  - 副标题随故事变化：“影像与手迹 / 影像与街巷 / 影像与手艺”；
  - 竖幅报道截图使用 `contain`，保留完整字幕；横幅纪实画面使用 `cover`，保持电影画幅；原片字幕和“九派新闻”“顶端新闻”等台标均不裁掉。
- 胶片下方可“暂停流转 / 继续流转”；打开全屏页时主视频自动暂停，关闭后恢复播放。
- 支持 ESC、右上角“回到街上”关闭，关闭后焦点回到刚才那张便签；手机端三炉都改为上下排版，实测均为刚好一屏。

## 四、一方水土页（本轮重做）

- 走到左边照片墙，墙上的大相框使用参考模板的 **ripple（涟漪）着色器**：换照片时从指针/点击的位置荡开一圈水纹；相框有木质外框、米色卡纸、黄铜包角和“这一路”小铜牌，旁边还挂两张小照片。
- 打开照片墙后不再是深色抽屉，而是照参考 frame 的做法：**3D 相框保持可见，底部浮出一条暖色玻璃标题栏和一排大幅 4:5 倾斜照片卡**。鼠标掠过卡片会立刻换到 3D 相框并从指针处荡开涟漪；左右拖动、横向滚轮、两侧箭头都能翻，松手自动吸附到最近一张。右上角显示当前张数（1 / 38）。
- 38 张照片全部来自你给的《匠心照片墙.docx》：保留原来那张武汉热干面当第一张，其余 37 张按原顺序排入。每张都配了短题、一行小注和题材小签，悬停/点击即可在 3D 相框里看大图。
- 照片数据全部集中在 `js/jiangxin-photos.js` 的 `window.JIANGXIN_PHOTOS` 里，每条包含 `id / title / note / tag / alt / src`。如果想改标题或顺序，只动这个文件即可。
- 38 张图都内嵌成 data URI，但**不会一次全部塞进显存**：首屏只加载前两张，其余卡片进入视野附近才解码；3D 相框的纹理缓存只保留最近几张，超出就释放旧纹理，手机也不会被 4MB 图片拖垮。要换图仍只需改这一个文件，把新图压到最长边约 1000–1200px、JPEG 质量 82% 左右，再转成 base64 `data:image/jpeg;base64,...` 填进 `src`。必须用 data URI，是因为 `file://` 下 WebGL 不能直接读取本地图片作为纹理；这样双击打开也能正常显示。
- 照片墙放在章节最后：看完可以 ESC 或“回到厨房”关掉浮层，也可以从页脚进入下一章“人间烟火”。

## 九、交互与实现要点

- **镜头路径**：桌面和手机各有一套机位关键帧，按滚动进度插值；镜头高度约 1.7m，尽量接近人眼。
- **进度映射**：街口与五个档口、街尾目录各有对应的滚动中心点，滚动到档口附近时画面/文字同步换位。
- **店铺交互**：Raycaster 命中门脸与柜台；悬停出提示，点击进入进店过渡，再跳转到目标页面；`Ctrl/Cmd + 点击`保留新标签打开。
- **时间**：`TIME_STOPS` 把滚动进度映射到分钟，`TIME_KEYS` 定义清晨/正午/黄昏/入夜/深夜的天空、雾、光强与曝光。
- **渲染**：Three.js 场景 + `EffectComposer` 的 Bloom 和最终调色 Shader（ACES、gamma、暗角、颗粒）。
- **性能**：手机/低性能设备会自动降低像素比、粒子数和灯笼数量；`prefers-reduced-motion` 下关闭步伐起伏、蒸汽漂移与光尘。
- **降级**：WebGL 不可用时页面会加 `no-webgl`，显示静态街景兜底，正文与导航仍可正常使用。
